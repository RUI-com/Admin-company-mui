## Getting Started

### Prerequisites
- Node.js 18+

### Install
```bash
npm install
```

### Run Dev Server
```bash
npm start
```

### Build
```bash
npm run build
```

### Project Entry
- `src/index.js` bootstraps React with `BrowserRouter`.
- `src/App.js` configures theme, layout (`Sidebar`, `Topbar`), and routes.
